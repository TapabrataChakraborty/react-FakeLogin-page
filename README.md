# React Login Page

A beginner React project built to practice controlled
forms, useState, conditional rendering and CSS glassmorphism.

## Features

- Email input
- Password input
- Form validation
- Error messages
- Login state
- Glassmorphism UI
- Responsive layout

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Vite

## Run Locally

npm install
npm run dev
